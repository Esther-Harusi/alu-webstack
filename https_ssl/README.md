# ALU Web Stack

This repository contains projects for the Web Infrastructure track at ALU, covering DNS, load balancing, and HTTPS/SSL configuration.

## https_ssl

Scripts for configuring DNS subdomains and HTTPS/SSL termination with HAProxy.

- `0-world_wide_web`: Displays DNS A record information for the www, lb-01, web-01, and web-02 subdomains of a given domain.
